TMNT 1.0.3: game controllers' mappings, and a log of what the game sees of them. As before, nothing of the game
comes in these packages: keep your own `tmnt.zip` (MAME's ROM set, World 4 Players) beside the game, and it takes
its assets out of it the first time it starts. The devices' games (Switch, Android, Anbernic) are made again with
the tools in the package.

**Fixed**

- **Game controllers SDL did not know** (a player's Nvidia Shield: a PS4 controller that did not move the menus'
  cursor, and in a game neither it nor an Xbox controller moved the turtle): the community's mappings,
  [SDL_GameControllerDB](https://github.com/mdqinc/SDL_GameControllerDB), are built into both games on the
  computers and Android. Not yet tried on a Shield.

**New**

- **The controllers in the log**: what the game finds of each controller (its name, GUID, and whether and how it is
  mapped), and the first keys and buttons pressed. If a controller still misbehaves, the log tells why: on Android
  it is `Android/data/io.github.cheviman.tmnt/files/tmnt.log` (`tmnt-arcade.log` for TMNT Arcade); on Linux and
  macOS it goes to the terminal the game was started from.

`README.txt` in the package says what each tool needs. What a tool makes is yours alone: never share it.
